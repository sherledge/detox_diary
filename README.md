🧠 DetoxDiary

A Flutter mobile app that helps you take control of your dopamine habits: cut down on the activities that drain you and build up the ones that make you better.

✨ Features

🚫 Bad dopamine activities: keep a list of habits you want to cut down (gaming, social media, binge watching, junk food, shopping and more), and add or remove your own.
✅ Good dopamine activities: track healthy habits like reading, exercise, yoga, meditation, outdoor activities, learning and creative work.
☑️ Daily check-in: mark each good activity as done or skipped with a tap.
📊 Stats tab: see your progress over time.
👥 Community tab: connect with others on the same journey.
🎨 Clean, minimal interface with simple bottom navigation.

🚀 Getting Started
Prerequisites
Flutter SDK
Android Studio or VS Code with the Flutter extension
An emulator or a physical device
Run locally
bash
# Clone the repository
git clone https://github.com/sherledge/detox_diary.git
cd detox_diary

# Install dependencies
flutter pub get

# Run the app
flutter run
Build an APK
bash
flutter build apk --release
